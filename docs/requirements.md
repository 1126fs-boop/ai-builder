# Requirements — Version 1.0 要件定義

## 概要

| 項目 | 内容 |
|---|---|
| プロダクト名 | AI Builder |
| 対象ユーザー | 美容機器・商材メーカーの BtoB 営業担当者 |
| ターゲット Version | **1.0** |
| プラットフォーム | Web アプリ（スマホファースト） |
| 技術方針 | HTML / CSS / JavaScript（フレームワーク不使用） |

---

## 1.0 の定義

> **営業担当者が、主要12シーンの AI を質問に答えるだけで作成し、保存・再利用・共有できる状態。**

---

## 機能要件

### FR-01: カテゴリ別 AI 作成（コア）

| ID | 要件 | 優先度 |
|---|---|---|
| FR-01-1 | 12カテゴリ以上から AI プロンプトを作成できる | Must |
| FR-01-2 | 各カテゴリは質問フロー（1問ずつ表示）で入力 | Must |
| FR-01-3 | 回答をもとに完成プロンプトを自動生成 | Must |
| FR-01-4 | 生成プロンプトをワンクリックでコピー | Must |
| FR-01-5 | 営業種別・取引先業種・経営課題を質問に含む | Must |
| FR-01-6 | 自由入力（追加情報）を任意で受け付ける | Must |

**対象カテゴリ（1.0）**

1. 情報収集
2. 営業準備
3. テレアポ
4. 商談
5. 提案書
6. 議事録
7. ロープレ
8. メルマガ
9. SNS
10. POP / 販促
11. 画像生成
12. 教育
13. AI エージェント作成

---

## 非機能要件

### NFR-01: パフォーマンス

| ID | 要件 |
|---|---|
| NFR-01-1 | 初回表示 2秒以内（3G 相当） |
| NFR-01-2 | 画面遷移 300ms 以内 |
| NFR-01-3 | プロンプト生成（クライアント側）1秒以内 |

### NFR-02: 可用性

| ID | 要件 |
|---|---|
| NFR-02-1 | オフライン時は保存済み AI の閲覧のみ可能 |
| NFR-02-2 | LocalStorage 障害時もアプリがクラッシュしない |

### NFR-03: 保守性

| ID | 要件 |
|---|---|
| NFR-03-1 | カテゴリ追加は `categories.js` + `questions.js` のみで完結 |
| NFR-03-2 | ES Module による責務分離 |
| NFR-03-3 | 全ファイルに日本語コメント |

### NFR-04: セキュリティ

| ID | 要件 |
|---|---|
| NFR-04-1 | API キーをソースコードにハードコードしない |
| NFR-04-2 | 取引先情報は暗号化保存（1.0 Backend） |
| NFR-04-3 | HTTPS 必須（本番） |

### NFR-05: UI/UX

| ID | 要件 |
|---|---|
| NFR-05-1 | スマホファースト（375px 基準） |
| NFR-05-2 | Apple / ChatGPT / Linear / Notion 風デザイン |
| NFR-05-3 | 営業現場で片手操作可能 |
| NFR-05-4 | アクセシビリティ: キーボード操作・aria 属性 |

---

## 制約条件

- **フレームワーク不使用**（React / Vue 等は使わない）
- **美容 BtoB メーカー営業専用**（汎用化しない）
- **ソリューション営業前提**（商品押し売りプロンプトは生成しない）
- 1.0 までは **段階的リリース**（0.x で検証 → 1.0 で本番）

---

## 受け入れ基準（1.0 リリース）

- [ ] 13カテゴリすべてで質問フロー → プロンプト生成が動作する
- [ ] 生成プロンプトがソリューション営業原則に準拠している
- [ ] 保存・お気に入り・最近使った AI が機能する
- [ ] OpenAI / Claude / Gemini 向けプロンプト出力が選べる
- [ ] 営業担当者がスマホで商談前後に 3分以内で AI を作成できる
- [ ] ログイン後、複数端末で保存 AI が同期される

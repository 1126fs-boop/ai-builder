# UI Design — 画面設計・遷移・ルール

## デザイン原則

| 原則 | 説明 |
|---|---|
| **スマホファースト** | 375px 基準。営業現場での片手操作 |
| **白基調** | Apple / ChatGPT / Linear / Notion 風 |
| **余白を広く** | 情報密度より読みやすさ |
| **カード型 UI** | すべての選択肢・コンテンツをカードで表現 |
| **自然なアニメーション** | 200〜400ms、ease-out。派手すぎない |
| **3タップ以内** | ホーム → カテゴリ → 完成プロンプト |

### カラーパレット

| 用途 | 値 |
|---|---|
| 背景 | `#f7f7f8` |
| カード背景 | `#ffffff` |

| サブテキスト | `#6e6e80` |
| アクセント | `#2563eb` |
| 成功 | `#059669` |
| 星 / お気に入り | `#f59e0b` |
| ボーダー | `#ececf1` |

### 角丸

| サイズ | 値 | 用途 |
|---|---|---|
| sm | 10px | ボタン・選択肢 |
| md | 14px | カード・検索バー |
| lg | 20px | 質問カード・結果カード |
| full | 9999px | バッジ・トースト |

### 2. 質問フロー（`view-questions`）

**目的**: 1問ずつ回答を収集。戻っても回答保持。

```
┌─────────────────────────────┐
│  🏠 ホーム                    │
│  質問 3 / 8                   │
│  ████░░░░                     │
├─────────────────────────────┤
│  Q3                           │
│  お客様の経営課題               │
│                               │
│  ┌─────────────────────┐    │
│  │ 売上アップ            │    │
│  ├─────────────────────┤    │
│  │ 集客改善              │    │
│  ├─────────────────────┤    │
│  │ 客単価アップ          │    │
│  └─────────────────────┘    │
├─────────────────────────────┤
│  [ ← 戻る ]    [ 次へ → ]    │
└─────────────────────────────┘
```

**ルール**
- 選択肢タップで即選択（ハイライト）
- 「次へ」は回答必須（optional 除く）
- 最終問のボタンは「完成」
- 戻る: 前の問へ。Q1 では ホームへ

## UI コンポーネント規約

| コンポーネント | クラス | 用途 |
|---|---|---|
| プライマリボタン | `.btn--primary` | メインアクション |
| セカンダリボタン | `.btn--secondary` | 戻る・サブ |
| ゴーストボタン | `.btn--ghost` | ホームへ戻る等 |
| カテゴリカード | `.category-card` | カテゴリ選択 |
| リストアイテム | `.list-item` | 最近・お気に入り |
| 選択肢 | `.option-btn` | 質問の選択肢 |
| 進捗セグメント | `.progress-segments__item` | 進捗バー |
| トースト | `.toast` | 通知 |

## レスポンシブ

| ブレークポイント | レイアウト |
|---|---|
| < 520px | カテゴリ 2列、片手操作最適化 |
| 520px〜 | カテゴリ 3〜4列 |
| 768px〜 | 余白拡大、max-width 720px 中央 |

---

## アクセシビリティ

- すべてのボタンに `type="button"`
- 進捗バーに `role="progressbar"` + `aria-valuenow`
- 選択肢に `role="option"` + `aria-selected`
- トーストに `role="status"` + `aria-live="polite"`
- フォーカスリング: `box-shadow: 0 0 0 3px rgba(37,99,235,0.12)`
